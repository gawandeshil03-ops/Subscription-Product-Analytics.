# Tableau Analysis

This is the analytical layer of the project.

The Tableau workbook contains the complete reporting and visualization flow:

- Executive KPIs
- Signup trends
- Conversion analysis
- Subscription funnel
- Revenue / MRR-related metrics
- Active customers
- Churn
- Cohort retention
- Acquisition, country, and device breakdowns

Open `subscription_product_analytics_FINAL.twbx` in Tableau Desktop to explore the dashboards and underlying worksheets.
